# cat

Учебный проект на Си: утилита, повторяющая поведение GNU `cat`.

Читает файлы и выводит их содержимое в стандартный вывод. Поддерживает нумерацию
строк, схлопывание пустых строк и отображение непечатаемых символов.

## Сборка

Нужны `gcc` и `make`:

```bash
make
```

Собранный бинарник — `build/cat`. Компиляция идёт со стандартом C11 и флагами
`-Wall -Wextra -Werror`: любое предупреждение останавливает сборку.

## Запуск

```bash
./build/cat file.txt                # вывести файл
./build/cat a.txt b.txt             # несколько файлов подряд
./build/cat                         # читать стандартный ввод
echo hello | ./build/cat            # то же через конвейер
./build/cat a.txt - b.txt           # "-" в списке означает стандартный ввод
./build/cat -n file.txt             # с нумерацией строк
```

## Флаги

| Флаг | Действие |
|------|----------|
| `-b` | нумеровать только непустые строки, перекрывает `-n` |
| `-E` | показывать `$` в конце каждой строки |
| `-n` | нумеровать все строки |
| `-s` | схлопывать несколько пустых строк подряд в одну |
| `-T` | показывать табуляцию как `^I` |
| `--help` | вывести справку и завершиться с кодом 0 |

Флаги можно склеивать: `-nE` равнозначно `-n -E`. Порядок аргументов не важен,
флаги могут стоять после имён файлов.

Код возврата: `0` при успехе, `1` при любой ошибке — как у GNU `cat`.

## Чем отличается от GNU cat

- Нет флагов `-A`, `-v`, `-e`, `-t`, `-u` и `--version`.
- Из длинных вариантов поддерживается только `--help`: `--number`, `--show-ends`
  и прочие не распознаются.
- `--` не считается признаком конца опций.

Во всём остальном вывод совпадает с GNU `cat` побайтово — это проверяется
автоматически, см. ниже.

## Тесты

```bash
make test
```

Прогоняются два слоя: юнит-тесты отдельных функций и интеграционные тесты,
сравнивающие вывод с системным `/bin/cat` на наборе файлов и комбинаций флагов.
Подробности — в [tests/README.md](tests/README.md).

## Цели make

| Цель | Что делает |
|------|-----------|
| `make` | собрать `build/cat` |
| `make run` | собрать и запустить на тестовых данных |
| `make test` | собрать и прогнать все тесты |
| `make val` | прогнать под `valgrind` |
| `make cln` | проверить форматирование (`clang-format -n`) |
| `make cli` | отформатировать исходники на месте |
| `make cpp` | статический анализ (`cppcheck`) |
| `make clean` | удалить `build/` |
| `make rebuild` | пересобрать с нуля |
